<p align="center">

## امکانات

- **پشتیبانی از همه‌ی نوع کانفیگ‌های رایج**
  - لینک‌های V2Ray: ‏`vless://` (همراه Reality)، ‏`vmess://`، ‏`trojan://`، ‏`ss://`، ‏`hysteria2://`، ‏`tuic://`. ترنسپورت‌ها: TCP، WebSocket، gRPC، HTTP/2، HTTPUpgrade.
  - SSH: با رمز عبور یا کلید خصوصی.
  - فایل‌های WireGuard (‏`.conf`) و OpenVPN (‏`.ovpn`)، مثلاً Windscribe. OpenVPN داخل خود موتور اجرا می‌شود و نصب برنامه‌ی جداگانه لازم نیست.
  - لینک‌های سابسکریپشن (base64 یا لیست ساده) و JSON مخصوص sing-box.
- **افزودن کانفیگ به هر روشی**: اول نوع را انتخاب کنید، بعد دستی وارد کنید، متن را پیست کنید یا فایل بدهید. می‌توانید چند لینک و چند سابسکریپشن را یک‌جا پیست کنید، یا هر جای برنامه <kbd>Ctrl</kbd>+<kbd>V</kbd> بزنید.
- **پینگ همه**: یک درخواست واقعی از طریق هر کانفیگ (پیش‌فرض: یوتیوب)، با نمایش لودینگ برای هر کانفیگ و مرتب‌سازی بر اساس پینگ.
- **کیل‌سوییچ**: یک بار روشنش کنید، از آن به بعد روی همه‌ی اتصال‌ها کار می‌کند. اگر VPN قطع شود، اینترنت قطع می‌شود. استثناها (دامنه، ‏`.ir`، IP و CIDR) همیشه از اینترنت عادی استفاده می‌کنند.
- **اتصال مجدد خودکار** با فاصله‌ی زمانی رو به افزایش و شمارش معکوس. وقتی کیل‌سوییچ روشن است، تلاش هیچ‌وقت متوقف نمی‌شود و هیچ ترافیکی نشت نمی‌کند.
- **تونل کل سیستم (TUN)**: همه‌ی برنامه‌ها از VPN رد می‌شوند و جلوی نشت DNS هم گرفته می‌شود.
- **سرعت لحظه‌ای**: سرعت فعلی، میانگین و حداکثر، تست سرعت، و نمودار مصرف ۷ روز اخیر.
- **بازخورد طراحی‌شده**: دیالوگ‌ها، پیام‌ها و صفحه‌های خطا داخل برنامه، و نوتیفیکیشن ویندوز با دکمه (اتصال دوباره / قطع اتصال).
- تم روشن و تاریک، طراحی رسپانسیو (ناوبری پایین صفحه در پنجره‌های باریک)، اجرا همراه ویندوز، و اتصال خودکار هنگام باز شدن برنامه.

## اجرا

پیش‌نیاز: ویندوز ۱۰ یا ۱۱ (۶۴ بیتی) و Node.js نسخه‌ی ۲۲ به بالا.

</div>

```bash
npm install          # آیکون پرچم‌ها هم کپی می‌شوند
npm run fetch-core   # موتور sing-box را در resources/bin دانلود می‌کند
npm run dev          # در ترمینالی که با Administrator باز شده اجرا کنید
```

<div dir="rtl">

رابط کاربری را می‌توانید با داده‌ی نمونه در مرورگر عادی هم ببینید: `http://localhost:3123`

## ساخت فایل نصبی

</div>

```bash
npm run dist
```

<div dir="rtl">

خروجی در مسیر `release/AntiVPN-Setup-<version>.exe` ساخته می‌شود. این فایل نصبی همه‌ی چیزهای لازم را دارد (موتور sing-box، پرچم‌ها و آیکون‌ها) و موقع اجرا دسترسی Administrator می‌خواهد.

## کیل‌سوییچ چطور کار می‌کند؟

وقتی VPN روشن است، sing-box همه‌ی ترافیک را از طریق یک رابط TUN با مسیریابی سخت‌گیرانه می‌گیرد. اگر سرور جواب ندهد، ترافیک به‌جای رفتن روی اینترنت عادی شما متوقف می‌شود. اگر خود موتور از کار بیفتد، یک کانفیگ «مسدودکننده» جایش را می‌گیرد تا VPN دوباره وصل شود. استثناها قبل از VPN مستقیم مسیریابی می‌شوند. وقتی خودتان قطع می‌کنید، همه‌چیز آزاد می‌شود.
